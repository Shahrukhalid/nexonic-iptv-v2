What it is

Nexonic IPTV v2 is the desktop and Smart TV companion to Nexonic IPTV, the curated list of official free-to-air channels. Run it on your computer to browse thousands of free channels by country, category or language and see which streams are working right now.

It can also act as an Xtream Codes API and M3U server, so IPTV Smarters, TiviMate or any other Xtream Codes player can log in to your own computer.

Limits. Nexonic IPTV v2 does not host any streams. It does not unlock paid channels, bypass DRM or get around regional restrictions, and it is not a subscription service. Only watch channels you are entitled to in your country.

Features

Worldwide live TV browser

Search by channel, country, language or category, with country flags and A to Z category navigation.

Real stream checks

HTTP status, latency, HLS manifest and segment checks, DRM detection and optional ffprobe probing. Dead links are flagged, not hidden.

Channel health center

Working, unstable, offline and region-restricted counts, with CSV and JSON exports.

Xtream Codes API and M3U server

player_api.php, get.php and xmltv.php endpoints for Smart TV apps.

TV guide (EPG)

XMLTV import with now and next listings.

Favourites and history

TV series channels, favourites and watch history, all stored locally.

Offline library

Play video files you put in local-data/offline_media/.

Bring your own playlists

Add any M3U URL or upload a file from the Sources page.

Privacy and safety

  • Local only by default: the server listens on 127.0.0.1.
  • No telemetry, analytics, tracking or account; data stays in local-data/.
  • Each install gets a random Smart TV password you can change in Settings.
  • Not an open proxy: the relay only forwards hosts in your catalogue and blocks private and cloud-metadata addresses.
  • Adult-oriented entries are skipped when playlists are imported.

Quick start

Requirements: Python 3.10+, Node.js 18+, and optionally ffmpeg for ffprobe checks.

Install and start

git clone https://github.com/Shahrukhalid/nexonic-iptv-v2.git
cd nexonic-iptv-v2
bash scripts/setup.sh   # backend venv, packages, web app build
bash scripts/start.sh   # then open http://localhost:8000

The first start imports the default playlists in the background; use the Channel Health page to check streams.

Frequently asked questions

What is Nexonic IPTV v2?

A self-hosted IPTV player and Xtream Codes server for free, legal TV channels. It runs on your own computer, verifies streams and lets you watch on a Smart TV.

Does it provide or host TV channels?

No. It does not host any streams. The default sources are Nexonic IPTV (official broadcaster streams) and the public iptv-org playlists, and you can add your own M3U playlists.

How do I watch on a Smart TV?

Set NEXONIC_HOST=0.0.0.0 in .env and restart, open Connect Smart TV in the app for your server URL, username and password, then choose Xtream Codes API in IPTV Smarters, TiviMate or a similar app. Keep it on your home network and do not forward the port on your router.

Is it safe to run?

It listens on 127.0.0.1 by default, has no telemetry, generates a random Smart TV password per install, and its stream relay is not an open proxy.

Can it unlock paid channels or bypass regional restrictions?

No. It does not unlock paid channels, bypass DRM or get around regional restrictions.

What do I need to run it?

Python 3.10+, Node.js 18+, and optionally ffmpeg for ffprobe codec and resolution checks.

What licence is it under?
